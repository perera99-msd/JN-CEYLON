## 🔑 Authentication

All endpoints except `/api/auth/login`, `/api/health`, and `/api/ready` require an authenticated session. Send the session cookie with every request.

### POST `/api/auth/login`

Log in and create a session.

**Body:**
```json
{
  "username": "admin",
  "password": "your-password"
}
```

**Response `200`:**
```json
{
  "_id": "64a...",
  "username": "admin",
  "fullName": "JN Ceylon Administrator",
  "role": "ADMIN"
}
```

**Errors:** `400` Missing credentials · `401` Invalid credentials

---

### GET `/api/auth/me`

🔒 **Requires Auth** — Check current session and get user info.

**Response `200`:**
```json
{
  "_id": "64a...",
  "username": "admin",
  "fullName": "JN Ceylon Administrator",
  "role": "ADMIN"
}
```

**Errors:** `401` Not authenticated

---

### POST `/api/auth/logout`

Log out and destroy the session.

**Response `200`:**
```json
{
  "message": "Logged out successfully"
}
```

---

### POST `/api/auth/change-password`

🔒 **Requires Auth** — Change current user's password.

**Body:**
```json
{
  "currentPassword": "old-password",
  "newPassword": "new-password"
}
```

**Response `200`:**
```json
{
  "message": "Password updated successfully"
}
```

**Errors:** `400` Validation error / Incorrect current password · `401` Not authenticated

## 📝 Quotations

> 🔒 All quotation endpoints require authentication.

### GET `/api/quotations`

List all active quotations (non-deleted).

**Response `200`:** Array of quotation objects with populated company.

---

### GET `/api/quotations/:id`

Get a single quotation by ID.

**Response `200`:** Quotation object with populated company.

**Errors:** `404` Not found

---

### POST `/api/quotations`

Create a new quotation.

**Body:**
```json
{
  "date": "2026-09-05",
  "company": "64a...",
  "custCode": "Halav 05",
  "preparedBy": "JN Ceylon",
  "items": [
    {
      "no": "1",
      "name": "Ceylon Cinnamon",
      "qty": 100,
      "desc": "Premium grade",
      "price": 25.00,
      "total": 2500.00
    }
  ],
  "subtotal": 2500.00,
  "tax": 0,
  "discount": 0,
  "iva": 0,
  "grandTotal": 2500.00,
  "terms": {
    "price": "All prices in USD",
    "delivery": "3-4 weeks",
    "term": "Payment upon confirmation",
    "validity": "30 Days"
  }
}
```

> 💡 `quotationNo` is auto-generated by the sequence service.

**Response `201`:** Created quotation object.

---

### PUT `/api/quotations/:id`

Update an existing quotation.

**Body:** Same fields as POST (partial updates supported).

**Response `200`:** Updated quotation object.

---

### DELETE `/api/quotations/:id`

Soft-delete a quotation (moves to Recycle Bin).

**Response `200`:**
```json
{
  "message": "Quotation moved to recycle bin"
}
```

---

### PUT `/api/quotations/:id/status`

Update quotation status.

**Body:**
```json
{
  "status": "SENT"
}
```

**Valid statuses:** `DRAFT`, `SENT`, `PO_RECEIVED`, `CONVERTED`, `REJECTED`

---

### POST `/api/quotations/:id/convert`

Convert a quotation to an invoice.

**Body:**
```json
{
  "poNumber": "PO-2026-001"
}
```

**Response `201`:** Created invoice object.

---

### GET `/api/quotations/next-number`

Preview the next auto-generated quotation number.

**Response `200`:**
```json
{
  "nextNumber": "158RC578"
}
```

## 💰 Payments

> 🔒 All payment endpoints require authentication.

### GET `/api/payments`

List all active payments with populated invoice and company.

---

### POST `/api/payments`

Record a payment against an invoice.

**Body:**
```json
{
  "invoice": "64a...",
  "company": "64a...",
  "amount": 1000.00,
  "method": "BANK_TRANSFER",
  "reference": "TXN-12345",
  "date": "2026-09-05",
  "notes": "First installment"
}
```

**Payment Methods:** `BANK_TRANSFER`, `CHEQUE`, `CASH`, `OTHER`

**Side Effects:** Updates the linked invoice's `amountPaid`, `balanceDue`, and `status`.

---

### DELETE `/api/payments/:id`

Soft-delete a payment.

## 🗑️ Recycle Bin

> 🔒 Requires authentication.

```json
{
  "quotations": [...],
  "invoices": [...],
  "payments": [...],
```

---

## 📜 Activity Log

### GET `/api/activity`

🔒 **Requires Auth** — Retrieve paginated audit trail of system activities.

**Query Parameters:**
- `action` — Filter by action (`ALL`, `CREATE`, `UPDATE`, `DELETE`, `LOGIN`, `PAYMENT`, `DUPLICATE`)
- `entityType` — Filter by module (`ALL`, `QUOTATION`, `INVOICE`, `PAYMENT`, `COMPANY`, `USER`)
- `search` — Keyword search across descriptions and identifiers
- `page` — Page number (default `1`)
- `limit` — Items per page (default `20`, max `100`)

**Response `200`:**
```json
{
  "data": [
    {
      "_id": "...",
      "userName": "Admin",
      "action": "CREATE",
      "entityType": "QUOTATION",
      "entityIdentifier": "QT-0001",
      "description": "Created quotation QT-0001",
      "createdAt": "2026-09-05T12:00:00.000Z"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 1,
    "pages": 1
  }
}
```

## ❌ Error Responses

All error responses follow this format:

```json
{
  "message": "Error description"
}
```

### Standard HTTP Status Codes

| Code | Meaning |
|------|---------|
| `200` | Success |
| `201` | Created |
| `400` | Bad Request — missing or invalid input |
| `401` | Unauthorized — not logged in or session expired |
| `403` | Forbidden — insufficient permissions or CORS violation |
| `404` | Not Found |
| `500` | Internal Server Error |
| `503` | Service Unavailable — database not connected |
